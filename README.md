# The Baby Is Not Born with the Biceps

This folder is a complete web app. To install it on a phone it must be
opened once from an https:// web address (any free static host works:
GitHub Pages, Netlify, Cloudflare Pages). Upload the whole folder as is.

Then on the phone:
  iPhone:  open the address in Safari > Share > Add to Home Screen
  Android: open it in Chrome > Install app (or menu > Add to Home screen)

After that it runs with no signal. Your log is stored on the phone only;
use "Back up to spreadsheet" in the app to save a copy, and
"Restore from backup" to load one back.

To publish an update, change VERSION at the top of sw.js so phones
pick up the new files.
